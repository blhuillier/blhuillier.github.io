Model selection asks which of several models the data favour, or whether any of them is acceptable at all. The standard Bayesian approach compares evidences, but it can only rank the candidates: if the true model is not among them, it still picks the least wrong one.

With Hanwool Koo, Arman Shafieloo and Ryan Keeley, we built a frequentist alternative based on iterative smoothing. It tests each model on its own, without comparing it to an alternative, and can conclude that all the candidates are false. We compared both approaches on simulated supernova data for the Roman Space Telescope.
