La sélection de modèles cherche lequel de plusieurs modèles les données favorisent, ou si l’un d’eux est seulement acceptable. L’approche bayésienne standard compare les évidences, mais ne peut que classer les candidats : si le vrai modèle n’en fait pas partie, elle choisit quand même le moins faux.

Avec Hanwool Koo, Arman Shafieloo et Ryan Keeley, nous avons construit une alternative fréquentiste fondée sur le lissage itératif. Elle teste chaque modèle pour lui-même, sans le comparer à un autre, et peut conclure que tous les candidats sont faux. Nous avons comparé les deux approches sur des données simulées de supernovae pour le télescope spatial Roman.
